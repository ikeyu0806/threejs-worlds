# 湖畔 — Lakeside

`/Users/ikegayayuuki/workspace/blender-animation` から移管した、視点を操作できる3Dワールド。

形状の正本: `blender-works/assets/animations/lakeside_glow/`。このプロジェクトでは配置、描画、操作を担当します。

`npm run dev:lakeside` で起動し、`/lakeside/` を開きます。

ドラッグと矢印キーで視点を変え、Homeキーまたはボタンで戻せます。波、蛍、光の粒子の動きをまとめて停止・再開できます。音声はありません。形状は検査済みGLB、時間変化は `shared/experiences/generated/lakeside.js` のThree.js runtimeです。モデルは `blender-works` の3Dモデルカタログにも掲載します。
