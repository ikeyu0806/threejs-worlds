# AFTERLIGHT — 九龍北区

React + Vite + Three.jsで作った、ブラウザで歩ける架空のサイバーパンク街。ネオン看板、雑居ビル、室外機、濡れた路面、雨、霧、監視ドローン、ホログラムを手続き生成しています。外部の3Dモデルなしで動きます。

## 起動

```sh
npm install
npm run dev
```

表示されたURLを開いてください。通常は http://localhost:5173 です。

```sh
npm run build
npm run preview
```

## 操作

- **街を歩く**：WASDで移動。Shiftで走る。ドラッグで視点を動かす。
- **矢印キー**：上下で移動、左右で視点を回転。
- **モバイル**：矢印ボタンを長押しして移動、画面をドラッグして視点を変更。
- **H**：UIを隠す／表示。**Esc**：眺めるモードへ戻る。
- **街区ボタン**：龍門路地、電脳闇市、第九連絡橋へ移動。
- **表示設定**：雨、発光、霧、描画品質を変更。軽量モードでは反射を省略。
- **カメラ**：UIなしの風景を撮影。プレビュー内の「PNGを保存」でダウンロード。
- **環境音**：雨と低い都市の音をWeb Audioで合成。ユーザーがオンにしたときだけ再生。
- **一時停止**：街のアニメーションと移動を停止。

WebGL 2に対応したブラウザが必要です。OSの「視差効果を減らす」設定では、自動カメラの揺れ、雨・ドローン等の移動を抑えます。背景タブでは描画を休止します。
