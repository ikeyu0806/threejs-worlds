# Visual references

屋台と雨合羽の通行人は blender-works の worlds hero kit（`noodle_stall.glb`、`rain_person.glb`）です。狭い路地、頭上の配線、濡れた路面は Cyberpunk 2077 の Japantown / Kabuki、およびブレードランナー以降のアジア系ネオノワールを参照しています。

2026-10-01に「cyberpunk asian alley neon rain night city」でWeb画像検索。提供されたGoogle画像検索の方向性から、狭い路地、突き出す縦看板、頭上の配線、濡れた路面、暖色と青緑の混在を採用。

| 作品 | 作者／サイト | 採用した視覚要素 |
| --- | --- | --- |
| [Cyber Streets](https://www.renderhub.com/gallery/50113/cyber-streets) | HelloRuler / RenderHub | 雑居ビルの密度、医療・店舗の看板、湿った路面 |
| [Cyber night city](https://displate.com/displate/7391931) | Dafikunn / Displate | 赤い提灯、店先と高層ビルの混在 |
| [Neo Tokyo](https://foundation.app/tokyoluv/foundation/10249) | tokyoluv / Foundation | 日本の路地の生活感、軒先の光、狭い街路 |
| [Japan Neon Alley](https://displate.com/displate/7413490) | Space Art / Displate | 雨、霧、青緑と赤紫、頭上の配線 |

参考画像の著作権は各作者に帰属します。アプリ内では出典へのリンクとリモートの参考画像を紹介しています。3Dの形状、看板、コンクリート、路面、ポスター、霧のテクスチャはオリジナルです。

技術資料： [Three.js Color Management](https://threejs.org/manual/pages/color-management.html)、[UnrealBloomPass](https://threejs.org/docs/pages/UnrealBloomPass.html)。
