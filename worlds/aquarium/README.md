# PELAGIC — 静かな海の水族館

大水槽を眺める水族館です。アクリルの大窓、光の筋、魚群、マンタ、ウミガメ、クラゲに加え、水槽を横切るジンベエザメを置いています。ジンベエザメの形状は blender-works の worlds hero kit です。水槽の構成は沖縄美ら海水族館の黒潮の海、光の降り方は ABZÛ のような体積光を参照しています。

ルートで `npm install`、`npm run dev` を実行し、`http://localhost:5173/aquarium/` を開いてください。

- 展示ボタンで観覧位置を切り替え、ドラッグで見回せます。
- 「館内を歩く」で WASD・矢印キー・タッチボタンによる移動ができます。Shift で速く移動し、Esc で戻れます。
- H で UI を切り替えられます。右下から生きものの動きを停止し、風景を PNG 保存できます。
- 館内ガイドで軽量表示に切り替えられます。動きを減らす設定と背景タブの描画休止に対応しています。

WebGL 2 対応のブラウザが必要です。将来追加するモデルの仕様は [MODEL_BRIEF.md](./MODEL_BRIEF.md) に記載しています。
