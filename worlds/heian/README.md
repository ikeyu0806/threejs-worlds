# HEIAN — 雅の古都

朝霧の庭、朱雀門、池を歩く Three.js の古都です。池には鯉が回り、門や松、花、月は手続き生成しています。

ルートで `npm install`、`npm run dev` を実行し、`http://localhost:5173/heian/` を開いてください。

- 展望ボタンで門・池・縁側を切り替え、ドラッグで見回せます。
- 「庭を歩く」で WASD・矢印キー・タッチボタンによる移動ができます。Shift で速く移動し、Esc で戻れます。
- H で UI を切り替えられます。右下から花の動きを停止し、風景を PNG 保存できます。
- 都の案内で軽量表示に切り替えられます。動きを減らす設定と背景タブの描画休止に対応しています。

WebGL 2 対応のブラウザが必要です。外部モデルなしで動作します。Google Fonts を利用し、読み込めない場合は端末のフォントで表示します。

## Blenderで制作した古都

門・寺院・塀・灯籠・松・桜・縁側・池の石・鯉・飛石・遠景の山を `blender-works/assets/environments/worlds_detail_kit/heian.py` で制作する。瓦の反りと稜線、斗栱、扉の鋲と引手、格子、木目、枝と葉をGLBに保存し、水面・朝霧・月光・舞う花びらは画面側で表現する。

配布GLBの制作commit、SHA256、実測budgetは `public/models/detail-manifest.json` に記録。高品質はPBR環境反射と影、軽量/mobileは影を省略する。鯉はモデルの部品をまとめて描画し、動きを減らす設定でも初期配置する。
