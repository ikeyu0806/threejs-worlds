# HEIAN — 雅の古都

朝霧の庭、朱雀門、池を歩く Three.js の古都です。門や松、花、月は手続き生成しています。

ルートで `npm install`、`npm run dev` を実行し、`http://localhost:5173/heian/` を開いてください。

- 展望ボタンで門・池・縁側を切り替え、ドラッグで見回せます。
- 「庭を歩く」で WASD・矢印キー・タッチボタンによる移動ができます。Shift で速く移動し、Esc で戻れます。
- H で UI を切り替えられます。右下から花の動きを停止し、風景を PNG 保存できます。
- 都の案内で軽量表示に切り替えられます。動きを減らす設定と背景タブの描画休止に対応しています。

WebGL 2 対応のブラウザが必要です。外部モデルなしで動作します。Google Fonts を利用し、読み込めない場合は端末のフォントで表示します。
